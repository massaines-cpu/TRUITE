# Documentation Frontend - Projet Truite

## Présentation

Le frontend utilise HTML, CSS, JavaScript et jQuery.
Les formulaires communiquent avec le backend grâce à AJAX.

---

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- jQuery

---

---

## Fonctionnement du Register

Le formulaire register :

- Vérifie les mots de passe
- Affiche un aperçu de l’image
- Envoie les données via AJAX
- Affiche un message de succès
- Affiche un message d’erreur

---

## Fonctionnement du Login

Le formulaire login :

- Envoie username et password_hash
- Vérifie les informations
- Affiche un message succès/erreur

---

## JavaScript

Le fichier app.js contient :

- Validation mot de passe
- AJAX register/login
- Preview image
- Gestion des messages utilisateur
